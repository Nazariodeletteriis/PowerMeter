# Changelog (zh-Hans)

Translation of CHANGELOG.md: same `## <version>` sections and bullets.

## 0.3.6

- 修复：修复了管理面板列出用户时赞助者页面导致窗口变黑的问题；页面出错时会显示错误和重试按钮，而不是黑屏。

## 0.3.5

- 新增：位于副本内的怪物会显示标有副本入口的世界地图和副本链接，Verteron 的 Illusion Curtain 层怪物现在也会显示在 Verteron 地图上。

## 0.3.4

- 新增：Patreon 上线赞助者方案（Recluta 3 €、Daeva 7 €、Empyrean 15 €，每月）。计量器和大部分标签页仍然免费；数据库、战斗报告、在线日志和排行榜需要 Recluta，队伍与循环、制作和计算器需要 Daeva。锁定的标签页仍留在菜单中，显示锁形图标和模糊预览。
- 新增：所有功能可免费试用 14 天，每个 Discord 账号限一次：使用 Discord 登录即可开始。
- 新增：每个账号的方案最多可在 2 台电脑上使用（30 天未使用的电脑会释放名额），免费试用每人一次，同时绑定 Discord 账号和电脑。
- 新增：赞助者页面：显示你的方案及其来源，可连接或断开 Patreon，并将各方案并列比较。
- 新增：社区配装展示来自 questlog.gg 的社区构筑，可按职业、标签、地区和关键字筛选；在 Character Builder 中打开任意一个并复制，即可变成你自己的构筑。
- 新增：NPC、怪物和副本的卡片会显示其所在位置的小地图，任务卡片会显示任务发布者、目标、交付 NPC 和副本的位置。新增了 Poeta、Ishalgen、Eltnen 和 Morheim 的地图。
- 变更："我的配装"只显示你创建或复制的构筑；"喜欢"现在改为"收藏"，并会在重启后保留。
- 变更：地图现在只加载你正在查看的部分。

## 0.3.3

- 新增：数据库中的 NPC 和怪物可在地图上显示刷新点（在地图上显示），适用于贝尔特伦、阿尔特加德和深渊。
- 变更：主构筑改为按角色而非按职业保存：同职业的两个角色拥有各自的装备。在角色编辑自己的构筑之前，会从之前共享的构筑开始。
- 变更：“我的角色”中的卡片改为显示角色主构筑的 Gear Score（已有 / 目标，与 Character Builder 中的数值相同），不再显示始终为空的 CP；顶部栏也不再显示 CP。
- 修复：从角色卡片打开的构筑会使用该角色的Arcana 与 Daevanion，而不是当前角色的。

## 0.3.2

- 修复：在“我的角色”中，点击整张角色卡片即可打开其构筑（之前只有名称可以点击，且没有任何视觉提示）。
- 修复：计量器会跟随从游戏中读取的、你实际正在游玩的角色；在“我的角色”中设置当前角色不再改变计量器追踪的对象。

## 0.3.1

- 新增：开始之前：在 PowerMeter 读取任何战斗数据之前，必须接受完整的使用条款和隐私政策（英语、意大利语、德语、法语、西班牙语、葡萄牙语、俄语）。现有用户在下次启动时接受一次即可。
- 变更：“打开小组件”现在改为“启动 DPSMeter”。
- 变更：在计量器、战斗历史和设置中，计量模式按 BOSS、TRAIN、PVE、PVP 的顺序显示。
- 变更：在“我的角色”中点击角色名称会打开其构筑，而不会更改当前角色。
- 变更：更新窗口按类型（新增、变更、修复）分组显示更新说明，更易阅读。
- 修复：Gear Viewer 会将大多数装备显示两次（同一物品每个阵营各有一份）；现在每件装备只显示一次。
- 修复：构筑标题栏显示的是占位的点赞数和评论数，而不是构筑的真实点赞数。

## 0.3.0

- 新增：在线日志：你上传的战斗，含链接、可修改的可见性（公开、不公开列出、私密）、浏览量、排名位置和删除。
- 新增：职业统计：根据社区上传的公开日志，显示每个首领的各职业平均 DPS、最常玩的职业和每周趋势。同一场战斗由多名队员上传只计一次。
- 新增：装备查看器：所有装备，支持筛选、搜索和按属性排序。选中物品可置顶或并排对比，最佳值显示绿色箭头，最差值显示红色箭头。
- 新增：军械库：按地区、种族、服务器和职业搜索角色，查看热门资料、排行榜和角色完整信息（EU/NA 开放后即可使用）。
- 新增：修果节：到下一轮的实时倒计时、本轮小游戏、后续轮次，以及显示所缺代币的节日商店规划。
- 新增：时空裂隙：传送门与裂隙倒计时、24 小时时间表以及你的种族路线。
- 新增：计算器：装备在两个强化等级间的属性与 Gear Score（含 soul imprint 品质）、主要属性加成，以及配方的 Splendent 概率。
- 新增：市场（取代购物清单）：物品搜索和关注列表；价格、趋势和市场统计将在有 EU/NA 市场数据源后显示。
- 新增：分步制作：每一步显示所用的具体物品、普通与 Splendent 结果以及下一步需要哪一个；在最后一阶可选择强化普通装备或制作直到出现 Splendent。
- 变更：Flow Map 由修果节取代；在线日志和职业统计会说明其用途。
- 修复：数据库中的翅膀、称号和宠物会显示其提供的加成。

## 0.2.14

- 新增：统计器新增 PvE 标签，用于刷怪。伤害会累计你击中的所有怪物，怪物死亡后依然保留，5 分钟未攻击怪物、切换区域或点击重置后清零。
- 新增：首领、PvE、训练和 PvP 相互独立：每次命中只计入其目标类型的标签。小组件始终显示正在记录的内容（类型和目标名称），保存的战斗进入对应标签，战斗记录中可按模式筛选。
- 新增：每名玩家受到的治疗（自身和他人）以及仇恨（受到怪物攻击的次数；守护星和剑星标记为 TANK；在怪物攻击任何人之前显示为估算值并予以标注）。
- 新增：制作：所有可制作物品（武器优先）、从第一阶到最后一阶的升级链、配方树，以及所选数量所需材料的已有和缺少数量，并会保存。
- 变更：所有位置（小组件、详情窗口、仪表盘统计器和报告）都显示完整伤害数值，不再按 K/M 取整。
- 修复：怪物移动时统计器不再停止计数（之前被误认为玩家），首领标签只显示首领。
- 修复：锁定小组件后玩家列表不再消失；锁定时配装和大厅保持可见。
- 修复：创建或重命名配装后，小组件依然显示已保存配装的图标。
- 修复：小组件中的上传会上传刚结束的战斗，需要时提示使用 Discord 登录，并提示训练战斗无法上传。

## 0.2.13

- 新增：角色有了种族（天族或魔族）。添加角色时选择，或在已有角色的卡片上选择；显示在主页和 Character Builder 中。
- 新增：战斗报告显示你保存的战斗：同一首领的尝试、概览、技能、DPS 图表、时间线、承受伤害、治疗和对比。在战斗记录或主页点击战斗即可在报告中打开。
- 新增：战斗报告中的导出会保存完整战斗，可通过 战斗记录 → 上传 → 从文件 重新载入。
- 新增：队伍分析显示你最近一场战斗的玩家、技能和开场循环。
- 变更：上线前已移除所有示例数据。暂时没有内容的页面（排行榜、社区配装、评论、新闻、活动、统计器的治疗与仇恨、小组件大厅）显示空状态。
- 变更：分享仅在从战斗记录上传战斗后提供真实链接。
- 变更：尚不可用的设置显示为禁用并标注“即将推出”。
- 修复：保留旧版本中保存的主配装装备。

## 0.2.12

- 新增：战斗记录中的上传会打开一个窗口，用于上传选中的战斗或用导出保存的文件，并可以在其中用 Discord 登录。
- 新增：重命名你创建或复制的构建并保存；你的构建上新增了编辑和删除按钮，并带有确认窗口。
- 新增：翅膀属性会显示已装备翅膀的加成，与收藏的加成分开显示。
- 变更：不提供属性的翅膀、称号和宠物会重新列出，排在其他项之后，标注为“无属性”。
- 变更：我的构建只列出你创建或复制的构建。
- 修复：下载 Npcap 会再次启动安装程序（现在会请求管理员权限，而不是静默失败）。

## 0.2.11

- 新增：Character Builder 中的属性变为真实且即时更新：职业基础属性、装备（魔石和其他所有栏位）、Daevanion、收藏和称号，均按照 questlog 的方式计算。目标视图会显示每项属性的变化。
- 新增：Pantheon、Arcana 和 Genus Insight 收藏，及其在构建器中的属性。
- 新增：数据库中的技能和任务会显示英文页面，下方显示你所选语言的同一页面（意大利语是非官方翻译）。
- 新增：删除你创建或复制的构建；重启后你的构建和 Daevanion 节点都会保留。
- 新增：新的 Windows 图标。
- 变更：装备评分按照 questlog 的方式计算（强化、突破、魔石、神石、Arcana、Daevanion 点数）。
- 变更：构建只能复制到相同职业的角色上。
- 变更：统一为一个返回按钮：从缺失部件返回构建，其他情况都返回 Character Builder。
- 修复：战斗记录中的上传会上传选中的战斗。
- 修复：已装备的翅膀和称号会提供其加成；没有属性的翅膀和称号不再列出；飞行力不再虚高。
- 修复：护手外观和 Brawler 的翅膀会隐藏，直到 Brawler 在 EU/NA 上线。

## 0.2.10

- 新增：Character Builder 收藏（外观、宠物、翅膀、石碑、称号）及真实属性合计；新角色从 0 开始。Genus Insight、Pantheon 和 Arcana 将在专门更新中推出。
- 新增：Character Builder 中的真实物品属性（基础、强化、突破、灵魂烙印），真实的魔石、神石和贤者之石，以及根据你的装备计算的装备评分。
- 新增：在物品页中，“添加到构建”将其放入当前装备，“添加到目标”放入目标装备。
- 新增：战斗报告中的对比和导出；战斗记录中的导出。
- 变更：副手栏位对所有职业都是 Guard；移除了潜力滑块；战斗力不再以虚构数字显示。

- 修复：缺失部件统计所有栏位（包括手镯）；当前装备把空构建显示为空；“返回构建”回到你正在编辑的构建。
