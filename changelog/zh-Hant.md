# Changelog (zh-Hant)

Translation of CHANGELOG.md: same `## <version>` sections and bullets.

## 0.2.13

- 新增：角色有了種族（天族或魔族）。新增角色時選擇，或在既有角色的卡片上選擇；顯示於首頁與 Character Builder。
- 新增：戰鬥報告顯示你儲存的戰鬥：同一首領的嘗試、概覽、技能、DPS 圖表、時間軸、承受傷害、治療與比較。在戰鬥紀錄或首頁點擊戰鬥即可在報告中開啟。
- 新增：戰鬥報告中的匯出會儲存完整戰鬥，可透過 戰鬥紀錄 → 上傳 → 從檔案 重新載入。
- 新增：隊伍分析顯示你最近一場戰鬥的玩家、技能與開場循環。
- 變更：上線前已移除所有範例資料。暫時沒有內容的頁面（排行榜、社群配裝、留言、新聞、活動、統計器的治療與仇恨、小工具大廳）顯示空狀態。
- 變更：分享僅在從戰鬥紀錄上傳戰鬥後提供真實連結。
- 變更：尚未開放的設定顯示為停用並標示「即將推出」。
- 修正：保留舊版本中儲存的主配裝裝備。

## 0.2.12

- 新增：戰鬥紀錄中的上傳會開啟一個視窗，用來上傳選取的戰鬥或用匯出儲存的檔案，並可以在其中用 Discord 登入。
- 新增：重新命名你建立或複製的配置並儲存；你的配置上新增了編輯和刪除按鈕，並附有確認視窗。
- 新增：翅膀屬性會顯示已裝備翅膀的加成，與收藏的加成分開顯示。
- 變更：不提供屬性的翅膀、稱號和寵物會重新列出，排在其他項目之後，標示為「無屬性」。
- 變更：我的配置只列出你建立或複製的配置。
- 修正：下載 Npcap 會再次啟動安裝程式（現在會要求管理員權限，而不是靜默失敗）。

## 0.2.11

- 新增：Character Builder 中的屬性變為真實且即時更新：職業基礎屬性、裝備（魔石和其他所有欄位）、Daevanion、收藏和稱號，均按照 questlog 的方式計算。目標檢視會顯示每項屬性的變化。
- 新增：Pantheon、Arcana 和 Genus Insight 收藏，及其在建構器中的屬性。
- 新增：資料庫中的技能和任務會顯示英文頁面，下方顯示你所選語言的同一頁面（義大利語為非官方翻譯）。
- 新增：刪除你建立或複製的配置；重啟後你的配置和 Daevanion 節點都會保留。
- 新增：新的 Windows 圖示。
- 變更：裝備評分按照 questlog 的方式計算（強化、突破、魔石、神石、Arcana、Daevanion 點數）。
- 變更：配置只能複製到相同職業的角色上。
- 變更：統一為一個返回按鈕：從缺少部件返回配置，其他情況都返回 Character Builder。
- 修正：戰鬥紀錄中的上傳會上傳選取的戰鬥。
- 修正：已裝備的翅膀和稱號會提供其加成；沒有屬性的翅膀和稱號不再列出；飛行力不再虛高。
- 修正：護手外觀和 Brawler 的翅膀會隱藏，直到 Brawler 在 EU/NA 上線。

## 0.2.10

- 新增：Character Builder 收藏（外觀、寵物、翅膀、石碑、稱號）及真實屬性合計；新角色從 0 開始。Genus Insight、Pantheon 和 Arcana 將在專門更新中推出。
- 新增：Character Builder 中的真實物品屬性（基礎、強化、突破、靈魂烙印），真實的魔石、神石和賢者之石，以及根據你的裝備計算的裝備評分。
- 新增：在物品頁中，「加入配置」將其放入目前裝備，「加入目標」放入目標裝備。
- 新增：戰鬥報告中的比較和匯出；戰鬥紀錄中的匯出。
- 變更：副手欄位對所有職業都是 Guard；移除了潛力滑桿；戰鬥力不再以虛構數字顯示。
- 修正：配置小工具顯示物品圖示。
- 修正：缺少部件統計所有欄位（包括手鐲）；目前裝備把空配置顯示為空；「返回配置」回到你正在編輯的配置。
- 修正：戰鬥報告中治療、承受傷害和目標的長條按整場戰鬥縮放，嘗試計數器可在各次嘗試間切換。
- 修正：Build community 的頭像顯示角色的臉。

## 0.2.9

- 新增：遊戲完整資料庫已收錄於應用程式（物品、NPC、任務、副本、技能、配方、稱號、成就、寵物、翅膀等），含真實詳情、條目互連和 Ctrl+K 搜尋。
- 新增：DPS Meter 的 PvP 分頁：你和隊伍對其他玩家造成的傷害。
- 新增：Character Builder 重做：每個欄位只提供對應類型的物品，滑桿和屬性選單可用，真實的目前與目標裝備、缺少部件、比較、小工具和分享（Discord）。
- 新增：Build community 每頁顯示 12 個配置；我的配置和已按讚可用。
- 變更：程式檔案現名為 PowerMeter.exe。
- 變更：頂部角色標籤是一個開啟我的角色的普通按鈕。
- 修正：匯出角色會將檔案儲存到下載資料夾。
- 修正：戰鬥報告的每個分頁（技能和增益時間軸、承受傷害、治療、目標）都會跟隨所選區間。
- 修正：預設裝備和配置列表跟隨你角色的職業。

## 0.2.8

- 新增：我的角色可用：新增、匯入、匯出、複製和刪除角色，並選擇目前角色。切換角色會更新整個面板（建構器、Skill Planner、Daevanion）。
- 新增：Daevanion Planner 顯示你角色職業的真實面板。
- 新增：建構器、物品頁、搜尋和首頁顯示真實物品圖示。
- 新增：附真實標記的互動式世界地圖（資料：aion2-interactive-map，CC BY-NC 4.0）。
- 新增：建立新配置時可選擇標籤。
- 變更：DPS Meter 的分頁現為 Boss、Train 和 PvP。
- 變更：僅顯示 EU 和 NA；Brawler 在西方上線前隱藏。
- 修正：切換 DPS Meter 分頁不再跳回 Boss。
- 修正：在戰鬥報告中選擇區間會更新下方的統計。
- 修正：排行榜的分頁與篩選以及 Build community 的頁碼可正常使用。

## 0.2.7

- 修正：更新視窗中的版本資訊現在會以你為 PowerMeter 選擇的語言顯示。
