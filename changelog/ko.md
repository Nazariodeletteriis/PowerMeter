# Changelog (ko)

Translation of CHANGELOG.md: same `## <version>` sections and bullets.

## 0.2.10

- 신규: Character Builder 컬렉션(스킨, 펫, 날개, 모놀리스, 칭호)과 실제 능력치 합계. 새 캐릭터는 0부터 시작합니다. Genus Insight, Pantheon, Arcana는 전용 업데이트로 제공 예정.
- 신규: Character Builder의 실제 아이템 능력치(기본, 강화, 돌파, 영혼 각인 줄), 실제 마석, 신석, 현자의 돌, 장비로 계산한 기어 점수.
- 신규: 아이템 페이지에서 '빌드에 추가'는 보유 장비에, '목표에 추가'는 목표 장비에 넣습니다.
- 신규: 전투 리포트의 비교와 내보내기, 전투 기록의 내보내기.
- 변경: 보조 손 슬롯은 모든 클래스에서 가드입니다. 잠재력 슬라이더를 제거했고, 전투력은 더 이상 임의의 숫자로 표시하지 않습니다.
- 수정: 빌드 위젯에 아이템 아이콘이 표시됩니다.
- 수정: 부족한 부위가 모든 슬롯(팔찌 포함)을 세고, 보유 탭은 빈 빌드를 비어 있게 표시하며, '빌드로 돌아가기'는 작업 중이던 빌드로 돌아갑니다.
- 수정: 전투 리포트의 치유, 받은 피해, 대상 막대가 전체 전투 기준으로 표시되고, 시도 카운터가 시도 사이를 이동합니다.
- 수정: Build community 초상화에 캐릭터 얼굴이 보입니다.

## 0.2.9

- 신규: 게임 데이터베이스 전체를 앱에 수록(아이템, NPC, 퀘스트, 던전, 스킬, 레시피, 칭호, 업적, 펫, 날개 등) — 실제 상세 정보, 항목 간 링크, Ctrl+K 검색.
- 신규: DPS Meter의 PvP 탭: 당신과 파티가 다른 플레이어에게 준 피해.
- 신규: Character Builder 개편: 각 슬롯은 해당 종류 아이템만 제안, 슬라이더와 능력치 메뉴 작동, 실제 보유/목표 장비, 부족한 부위, 비교, 위젯, 공유(Discord).
- 신규: Build community는 페이지당 12개 표시, 내 빌드와 좋아요 작동.
- 변경: 프로그램 파일 이름이 PowerMeter.exe로 바뀌었습니다.
- 변경: 상단 캐릭터 칩은 내 캐릭터를 여는 단순한 버튼입니다.
- 수정: 캐릭터 내보내기가 파일을 다운로드 폴더에 저장합니다.
- 수정: 전투 리포트의 모든 탭(스킬·버프 타임라인, 받은 피해, 치유, 대상)이 선택한 구간을 따릅니다.
- 수정: 기본 장비와 빌드 목록이 캐릭터 클래스를 따릅니다.

## 0.2.8

- 신규: 내 캐릭터 기능 작동: 캐릭터 추가, 가져오기, 내보내기, 복제, 삭제 및 활성 캐릭터 선택. 캐릭터를 바꾸면 대시보드 전체(빌더, Skill Planner, Daevanion)가 갱신됩니다.
- 신규: Daevanion Planner가 캐릭터 클래스의 실제 보드를 표시합니다.
- 신규: 빌더, 아이템 페이지, 검색, 홈에 실제 아이템 아이콘 표시.
- 신규: 실제 마커가 있는 인터랙티브 월드 맵(데이터: aion2-interactive-map, CC BY-NC 4.0).
- 신규: 새 빌드를 만들 때 태그 선택.
- 변경: DPS Meter 탭이 Boss, Train, PvP로 바뀌었습니다.
- 변경: EU와 NA만 표시되며, Brawler는 서구 출시 전까지 숨겨집니다.
- 수정: DPS Meter 탭을 바꿔도 더 이상 Boss로 돌아가지 않습니다.
- 수정: 전투 리포트에서 구간을 선택하면 아래 통계가 갱신됩니다.
- 수정: 랭킹 탭과 필터, Build community 페이지 번호가 작동합니다.

## 0.2.7

- 수정: 업데이트 창의 릴리스 노트가 이제 PowerMeter에서 선택한 언어로 표시됩니다.
