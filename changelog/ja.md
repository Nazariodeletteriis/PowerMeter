# Changelog (ja)

Translation of CHANGELOG.md: same `## <version>` sections and bullets.

## 0.2.11

- 新機能：Character Builder のステータスは実際のデータでリアルタイムに反映されます。クラスの基本ステータス、装備（マジックストーンとその他すべてのスロット）、Daevanion、コレクション、称号を questlog と同じ方法で計算します。目標ビューでは各ステータスの変化が表示されます。
- 新機能：Pantheon、Arcana、Genus Insight のコレクションと、ビルダーでのそのステータス。
- 新機能：データベースのスキルとクエストに英語版ページが表示され、その下に同じページのあなたの言語版が表示されます（イタリア語は非公式の翻訳です）。
- 新機能：作成または複製したビルドを削除できます。ビルドと Daevanion のノードは再起動後も保持されます。
- 新機能：新しい Windows アイコン。
- 変更：ギアスコアは questlog と同じ方法で計算されます（強化、突破、マジックストーン、テオストーン、Arcana、Daevanion ポイント）。
- 変更：ビルドは同じクラスのキャラクターにしか複製できません。
- 変更：戻るボタンを統一：不足パーツからはビルドへ、それ以外は Character Builder へ。
- 修正：戦闘履歴のアップロードが選択した戦闘をアップロードします。
- 修正：装備した翼と称号がボーナスを与えるようになりました。ステータスのない翼と称号は一覧に表示されなくなりました。飛行力が水増しされなくなりました。
- 修正：ガントレットのスキンと Brawler の翼は、Brawler が EU/NA でリリースされるまで非表示です。

## 0.2.10

- 新機能：Character Builder のコレクション（スキン、ペット、翼、モノリス、称号）と実際のステータス合計。新キャラクターは0から始まります。Genus Insight、Pantheon、Arcana は専用アップデートで対応予定。
- 新機能：Character Builder に実際のアイテムステータス（基本、強化、突破、魂の刻印）、実際のマジックストーン、テオストーン、賢者の石、装備から計算するギアスコア。
- 新機能：アイテムページの「ビルドに追加」は所持装備に、「目標に追加」は目標装備に追加します。
- 新機能：戦闘レポートに比較とエクスポート、戦闘履歴にエクスポート。
- 変更：サブハンドは全クラスでガードに。ポテンシャルのスライダーを削除。戦闘力は架空の数値で表示しなくなりました。
- 修正：ビルドウィジェットにアイテムアイコンを表示。
- 修正：不足パーツが全スロット（ブレスレット含む）を数え、所持タブは空のビルドを空と表示し、「ビルドに戻る」は作業中のビルドに戻ります。
- 修正：戦闘レポートの回復・被ダメージ・ターゲットのバーが戦闘全体を基準にし、挑戦回数のカウンターが挑戦ごとに切り替わります。
- 修正：Build community の肖像にキャラクターの顔が表示されます。

## 0.2.9

- 新機能：ゲームのデータベース全体をアプリに収録（アイテム、NPC、クエスト、ダンジョン、スキル、レシピ、称号、実績、ペット、翼など）。実際の詳細、項目間リンク、Ctrl+K 検索に対応。
- 新機能：DPS Meter に PvP タブ：あなたとパーティーが他のプレイヤーに与えたダメージ。
- 新機能：Character Builder を刷新：各スロットはその種類のアイテムのみ表示、スライダーとステータスメニューが動作、実際の所持・目標装備、不足パーツ、比較、ウィジェット、共有（Discord）。
- 新機能：Build community は1ページ12件表示。自分のビルドといいねが機能します。
- 変更：プログラムファイル名が PowerMeter.exe になりました。
- 変更：上部のキャラクターチップはマイキャラクターを開くシンプルなボタンになりました。
- 修正：キャラクターのエクスポートでファイルがダウンロードフォルダーに保存されます。
- 修正：戦闘レポートの全タブ（スキル・バフのタイムライン、被ダメージ、回復、ターゲット）が選択範囲に従います。
- 修正：初期装備とビルド一覧がキャラクターのクラスに従います。

## 0.2.8

- 新機能：マイキャラクターが使えるようになりました。キャラクターの追加・インポート・エクスポート・複製・削除、アクティブキャラクターの選択ができます。切り替えるとダッシュボード全体（ビルダー、Skill Planner、Daevanion）が更新されます。
- 新機能：Daevanion Planner がキャラクターのクラスの実際のボードを表示します。
- 新機能：ビルダー、アイテムページ、検索、ホームに実際のアイテムアイコンを表示。
- 新機能：実際のマーカー付きインタラクティブワールドマップ（データ：aion2-interactive-map、CC BY-NC 4.0）。
- 新機能：新しいビルド作成時にタグを選択できます。
- 変更：DPS Meter のタブは Boss、Train、PvP になりました。
- 変更：EU と NA のみ表示。Brawler は西欧版リリースまで非表示です。
- 修正：DPS Meter のタブを切り替えても Boss に戻らなくなりました。
- 修正：戦闘レポートで範囲を選択すると下の統計が更新されます。
- 修正：ランキングのタブとフィルター、Build community のページ番号が機能します。

## 0.2.7

- 修正：アップデート画面のリリースノートが、PowerMeter で選択した言語で表示されるようになりました。
